## Условия проверки

- Windows: Windows 11.
- .NET: .NET 8.0, целевая платформа `net8.0-windows`.
- SQL Server: Microsoft SQL Server 2022, экземпляр `DESKTOP-MTDRK23`, Windows Authentication.
- Подготовка БД: выполнены `database/schema.sql` и `database/seed.sql`. Исходное состояние: 5 участников, 5 категорий, 5 лотов (3 активных, 2 завершённых), 13 ставок, 2 победителя.
- Способ запуска: по README, командой `dotnet run` из папки `src/AuctionDesk.App`. Отклонений от инструкции не потребовалось.

## TC-08. Откат после ошибки внутри транзакции

**Тип:** отрицательный. Связь с требованиями: TX-01, BR-01, BR-02.

**Начальные условия:** лот iPhone 15 Pro активен, текущая цена 95000 ₽, по лоту 3 ставки, текущий пользователь elena_kuznetsova. Для проверки BR-02 подготовлен завершённый лот «Коллекция марок».

**Действия:** для воспроизведения ошибки после первого изменения в методе `PlaceBid` временно добавлен вызов `throw new Exception("Тест отката")` между вставкой в `bids` и обновлением `current_price`. Выполнена ставка, затем повторно прочитаны данные запросами `SELECT COUNT(*) FROM bids WHERE lot_id = 3` и `SELECT current_price FROM lots WHERE lot_id = 3`. После проверки временный вызов удалён, сборка восстановлена. Дополнительно выполнены попытки ставки с суммой, равной текущей цене, и ставки на завершённый лот.

**Ожидаемый результат:** при ошибке после вставки ставки транзакция откатывается полностью: новая запись в `bids` отсутствует, `current_price` не изменена, приложение сообщает об ошибке. При нарушении BR-01 и BR-02 операция отклоняется без изменения данных.

**Фактический результат:** при искусственной ошибке выведено сообщение «Ошибка: Тест отката», количество ставок по лоту осталось 3, цена осталась 95000.00 — частично сохранённых данных нет. При ставке, равной текущей цене, выведено «Ставка должна быть выше 95000.00 руб.», данные не изменились. Для завершённого лота кнопка ставки неактивна, при программном вызове выведено «Аукцион завершён, ставки запрещены».

**Статус:** Пройден.
