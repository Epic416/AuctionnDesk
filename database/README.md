# Развёртывание базы данных

## Параметры

| Параметр | Значение |
| --- | --- |
| Название базы | AuctionDesk |
| SQL Server | Microsoft SQL Server 2022 Express / LocalDB (проверено на обоих) |
| Аутентификация | Windows Authentication (Integrated Security=true) |
| Инструмент выполнения скриптов | SQL Server Management Studio (SSMS) 2022 |

## Порядок выполнения

1. Откройте SSMS и подключитесь к локальному экземпляру SQL Server:
   - Для LocalDB: сервер `(localdb)\MSSQLLocalDB`, аутентификация Windows
   - Для SQL Server Express: сервер `localhost\SQLEXPRESS` или `DESKTOP-<имя_ПК>\SQLEXPRESS`, аутентификация Windows
2. Убедитесь, что у вашего пользователя Windows есть права на создание баз данных.
3. Откройте файл `database/schema.sql` в SSMS и выполните его (клавиша **F5**). Скрипт:
   - Удаляет существующую базу `AuctionDesk` (если она есть)
   - Создаёт новую базу `AuctionDesk`
   - Создаёт 6 таблиц: `users`, `categories`, `auctions`, `lots`, `bids`, `winners`
   - Создаёт 5 индексов и представление `vw_auction_report`
4. Откройте файл `database/seed.sql` в SSMS и выполните его. Скрипт наполняет базу тестовыми данными.
5. Проверьте результат выполнения запросом:

USE AuctionDesk;
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_TYPE = 'BASE TABLE' ORDER BY TABLE_NAME;

## Повторный запуск

Скрипт schema.sql пересоздаёт базу данных с нуля: если база AuctionDesk уже существует, она удаляется командой DROP DATABASE и создаётся заново. Это означает, что при повторном запуске:
Все пользовательские данные, созданные через приложение, будут потеряны
База вернётся к исходному состоянию из seed.sql
Скрипт seed.sql можно запускать повторно — он сначала очищает все таблицы в обратном порядке (с учётом внешних ключей), а затем вставляет тестовые данные.

## Тестовые данные

Набор тестовых данных включает следующие сущности:
users (5 записей) — участники аукциона: ivan_petrov, maria_ivanova, alexey_smirnov, elena_kuznetsova, dmitry_volkov.
categories (5 записей) — категории лотов: Искусство, Антиквариат, Электроника, Коллекционирование, Ювелирные изделия.
auctions (3 записи) — два завершённых аукциона (completed) и один активный (active).
lots (5 записей) — лоты в разных категориях и аукционах: Картина "Закат", Старинные часы, iPhone 15 Pro, Коллекция марок, Золотое кольцо.
bids (13 записей) — ставки по лотам, включая несколько ставок на один лот.
winners (2 записи) — победители лотов из завершённых аукционов.
Этих данных достаточно для демонстрации всех функций приложения:
Каталог, поиск и фильтрация лотов.
Успешное внесение ставки (лот «iPhone 15 Pro», активный аукцион).
Отрицательный сценарий BR-01: ставка ниже текущей цены.
Отрицательный сценарий BR-02: ставка на закрытый аукцион.
Формирование отчёта по завершённым аукционам.
Создание нового аукциона и его завершение с определением победителей.

## Настройка подключения

Строка подключения задаётся в файле src/AuctionDesk.App/Data/Database.cs:
public static string ConnectionString { get; } = @"Server=(localdb)\MSSQLLocalDB;Database=AuctionDesk;Integrated Security=true;TrustServerCertificate=true;";

Используйте SQL-скрипты как воспроизводимый источник структуры и учебных данных. Файлы базы `.mdf`, `.ldf` и резервные копии не заменяют скрипты. Не привязывайте развёртывание к абсолютным путям своего компьютера.
